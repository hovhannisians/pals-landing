Each pal has a workspace on its computer: a folder that persists between chats, where it keeps files, writes code and saves what it makes for you.

## Sending files to a pal

Attach files to a message, up to 10 at a time.

- **Images** are shown to the model, so the pal can see them.
- **PDFs and other files** are saved to the pal's workspace, where it can open them with code. They aren't sent to the model directly.

## Files from a pal

When a pal finishes something you can take away, like a report, a spreadsheet, a chart or an export, it sends it to you in the chat with a notification. You can preview images, PDFs and text right there, or download anything.

## Running code

Pals write and run code in their workspace: scripts, data clean-up, downloads, charts, small tools. It runs on the pal's own cloud computer, powered by E2B, so it can install whatever packages it needs without touching your computer.

Ask for things like:

- "Turn this CSV of transactions into a chart of spending by month."
- "Download the last 12 months of my bank statements from Drive and add up the fees."
- "Write a script that checks this page every morning and tells me if the price changes."

## Browsing the workspace

The **Files** panel shows what's in a pal's workspace and lets you download any file from it.

## Limits

On hosted Pals, uploads can be up to 25 MB per file and 100 MB per message. The free plan has 1 GB of uploads a day.
